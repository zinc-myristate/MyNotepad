# 后续优化清单

保存日期：2026-10-30。当前已完成：主窗口视觉整理、轻量笔记列表、标题样式菜单、明确保存反馈、编辑／分栏／阅读切换、专注模式、可操作空白页、弹窗微动效与减少动态效果适配。

参考与本轮问题分析见 [界面评估](design-review.md)。以下是后续工作计划，尚未执行。

| 优先级 | 优化项 | 具体工作与验收 |
| --- | --- | --- |
| P0 | 更新实际运行版 | 备份现有 renderer 后同步源码改动；启动打包版检查新建、编辑、保存、导出、旧笔记与附件；记录回滚路径。当前 `dist/MyNotepad` 尚未更新。 |
| P0 | 键盘与焦点 | 为弹窗补全焦点约束、关闭后焦点返回；笔记列表支持方向键、Enter；逐项检查 Tab 顺序、Esc 行为和图标按钮标签。 |
| P1 | 工具入口整理 | 将高频动作与外观设置分组；长工具栏增加“更多”入口；完善命令面板的可发现性，保持旧功能可达。 |
| P1 | 长文与窄窗口 | 核对首次打开长笔记的滚动位置、视图切换后的阅读位置；覆盖 900×600 和 125%／150%／200% 缩放；检查超长标题、空笔记、大表格与图片。 |
| P1 | 动效打磨 | 统一抽屉、菜单、提示的进出节奏；补关闭过渡与快速连点中断；减少动态效果模式下不播放装饰动画，输入和虚拟滚动不等待动画。 |
| P1 | 主题与可读性 | 逐屏检查五套主题、背景图片和文字对比度；统一代码块、弹窗、下拉菜单和禁用状态；补充浅色、深色及最小窗口截图。 |
| P2 | CSS 整理 | 合并历史重复选择器，逐步移出行内样式；建立统一间距、圆角、字号、动效变量，保留自适应背景的覆盖规则。 |
| P2 | 性能与验证环境 | 用大量笔记验证滚动、搜索和快速切换；排查本机 WebView2 测试启动时的原生异常输出，提升测试可重复性。 |

建议下一轮顺序：先完成运行版更新与冒烟验证，再做键盘焦点和工具栏整理，最后集中验收动效与主题。
