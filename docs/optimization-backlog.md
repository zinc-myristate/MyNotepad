## 已完成

| 优先级 | 优化项 | 结果 |
| --- | --- | --- |
| P0 | 更新实际运行版 | 已用 `python build.py` 完整打包（此前是只替换 `_internal/renderer` 的热更新）。用用户库的隔离副本驱动真实 exe 验证了新建、编辑、保存、旧笔记与附件；导出只验证到前端把内容交给桥接，写文件要过系统保存对话框，这一步没有自动化。 |
| P0 | 键盘与焦点 | 弹窗有焦点约束和面板栈，关闭后焦点返回；×、Esc、点遮罩走同一条取消路径；笔记列表支持方向键、Home／End、Enter，`Tab` 能走到当前行的操作按钮；全部面板做过键盘可达性与读屏名称审计，并有回归测试。 |
| P1 | 矮窗口侧栏 | 窗口变矮时笔记列表优先：视图和标签收成单行窄条，工具收成一行图标（悬停或键盘聚焦显示文字），最矮时再隐藏副标题和列表小标题。900×600 下列表从 1.8 行到 4.3 行；有 12 个标签和 3 个视图时从 0 行到 3.3 行，底部不再被挤出窗口。没有标签和视图的库在 1200×800 下与改动前零像素差。 |
| P1 | 窗口几何 | 窗口最小化、最大化或隐藏时不再保存窗口大小，保留上一次的有效值；已经写坏的记录启动时当作没保存过，回到默认尺寸。 |

回滚路径：`dist/` 下的 `_rollback-*` 目录存着打包前的程序文件。先关掉记事本，用最新一份里的 `MyNotepad.exe` 和 `_internal` 替换 `dist/MyNotepad` 里的同名文件，笔记数据不受影响。

`build.py` 自己的 `_predist-backup-*` 只含 `data`、`resources` 和旧 exe，回滚不了程序本身。`restore_renderer.ps1` 只对应之前那次热更新，完整打包后会因为校验对不上而拒绝执行。
