回滚路径（先关掉记事本；不动笔记数据，第一条只校验不改文件）：

```powershell
powershell -ExecutionPolicy Bypass -File restore_renderer.ps1 -Backup dist\_renderer-backup-20261031-p0 -VerifyOnly
powershell -ExecutionPolicy Bypass -File restore_renderer.ps1 -Backup dist\_renderer-backup-20261031-p0
```

这份备份只对应这次热更新。之后用 `python build.py` 完整打包时，`dist/MyNotepad` 会整体重建，回滚脚本会因为校验对不上而拒绝执行。
