# MyNotepad 界面评估与第一轮改进

评估日期：2026-10-30。范围：Windows 桌面主窗口、笔记列表、Markdown 编辑、空白页、主题和微交互。

## 评价

优势是功能扎实：本地存储、自动保存、加密、全文搜索、双链、版本记录和 Markdown 都已有实现，前端也有虚拟列表与回归测试。现在最值得投入的是整理功能的呈现方式。

| 问题 | 对使用的影响 | 本轮处理 |
| --- | --- | --- |
| 侧栏卡片、工具按钮都有较重边框和阴影 | 所有内容都在争夺注意力 | 平静的侧栏底色、轻量列表、明确选中态、统一间距 |
| 标题旁常驻五个样式按钮 | 正文标题被工具挤压；空库还会残留按钮 | 收进可用键盘打开的 Aa 菜单，空状态隐藏整行 |
| 保存只显示一个小圆点 | 用户不容易判断是否落盘 | 增加“已保存到本地／正在保存／保存失败”状态文字 |
| Markdown 的工具栏与正文仍使用旧网格行号 | 新增属性行后，正文不能稳定占满剩余空间 | 标题、标签、属性、工具栏、正文、状态栏显式分配网格行 |
| 窄窗口始终挤两栏 | 源码和预览都难以阅读 | 按编辑区实际宽度选择单栏，增加编辑／分栏／阅读切换 |
| 每次重建虚拟列表都会播放错峰入场 | 滚动、搜索和刷新时产生闪烁、等待感 | 取消循环入场和悬停横移，保留轻微底色反馈 |
| 列表悬停按钮挤压标题 | 标题和日期跳动 | 按钮覆盖摘要区，标题位置保持稳定；日期缩短，完整日期保留悬停提示 |
| 空白页只有说明文字 | 新用户没有明确的下一步 | 增加可直接新建和查找笔记的操作 |

这里的“模仿”用于信息层级和交互原则。新增实现为本项目代码，未引入上游源码、图标、字体或网络资源。

## 使用与实现

- 顶部切换 Markdown 的编辑、分栏、阅读；偏好写入本地设置，重启后保留。分栏需要至少 740px 编辑区宽度。窗口变窄时临时回到编辑，重新加宽会恢复分栏偏好。
- 点击“专注”或按 `Ctrl+Shift+F` 隐藏侧栏，再次操作即可退出。视图变化不重建编辑器、不清空撤销历史。
- 左上角命令图标或 `Ctrl+P` 打开原有快速跳转和命令面板。
- 沿用五套主题和自定义背景；使用本地字体。系统启用减少动态效果时停止所有装饰动画。
- `renderer/workspace.css` 集中管理这一轮视觉规则；`31-workspace.js` 仅管理视图偏好与工作区交互。笔记内容和保存事务仍走现有实现。

## 后续优先级

1. 随功能继续增长，把工具入口按使用频率集中到更完整的命令面板与设置页。
2. 逐步合并历史 CSS 覆盖规则，减少重复声明，避免继续累积多个视觉来源。
3. 单独安排键盘导航与对话框焦点管理的全面检查。

本轮不改存储格式、加密方式和后台同步行为。
