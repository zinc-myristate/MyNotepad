# 我的记事本 (MyNotepad)

> Windows 桌面本地记事本 —— Python + pywebview 架构，纸质笔记本风格。
> 数据完全本地存储，便携模式（数据跟随 exe 目录），可拷到 U 盘随身携带。

## 技术架构

| 层 | 技术栈 |
|---|---|
| 前端 | pywebview + Quill.js v2 + KaTeX |

| 测试 | pytest（466 单测 + 76 无头 E2E） |

## 快速开始

**开发运行**（需要 Python 3.14 及依赖）：

```bash
pip install pywebview cryptography Pillow pystray opencv-contrib-python numpy python-docx openpyxl pytest
python app.pyw          # 或 py -3.14 app.pyw
```

**打包分发**：

```bash

```

**便捷启动**：`启动.bat` / `启动.vbs`（桌面快捷方式）；`诊断.bat` 排查环境问题。

## 数据与安全

- **数据目录**：`data/`（与 exe 同目录，便携模式；`MYNOTEPAD_DATA_DIR` 环境变量可覆盖，测试隔离用）
  - `notes.db` — 笔记数据库（正文为 Quill Delta JSON）
  - `attachments/` — 附件与图片
  - `backgrounds/` — 笔记背景图副本
  - `backups/` — 定期自动备份（>24h 触发，滚动保留 7 份，sqlite backup API 页级一致）
  - `error.log` — 崩溃兜底日志（1MB×2 轮转，绝不含笔记内容）
- **单实例**：重复启动会自动聚焦已有窗口（互斥量保证，避免并发写库冲突）
- **多设备同步（可选）**：把整个应用目录（含 `data/`）放入同步盘（坚果云 / OneDrive / Dropbox 等）即可多设备同步。注意：先退出应用、等同步完成后再在另一台设备打开；不要在两台设备同时运行应用（SQLite 并发写会锁冲突），不要在应用运行时手动覆盖同步来的文件
- **关窗兜底**：closing 事件「取消-冲洗-再关」，不等防抖的最后 500ms 输入也落库，3s 看门狗保证关得掉
- **加密设计**：每笔记随机 DEK（AES-256-GCM）加密正文与历史版本，DEK 被密码派生的 KEK 包裹（`dekv1:`），密文 AAD 绑定 note_id 防跨笔记移植；解锁状态只存后端进程内存；**忘记密码内容不可恢复**
- **全文搜索**：FTS5 trigram（中文可用）；加密笔记正文不入索引，只搜标题；<3 字符自动 LIKE 回退
- **图片外置**：图片落盘 `attachments/`，正文只存引用（Delta dict），不再内嵌 base64；启动时自动迁移存量图片（幂等，`data/backups/premig-*` 快照可回滚）；导出时自动重新内嵌

```bash
python build.py                    # 推荐：一条命令完成全部步骤
```

`build.py` 按 `关实例 → 备份 data/resources → PyInstaller → 还原数据 → 修快捷方式 → 冒烟启动`
执行，任一步失败都会**尽力还原数据**。

> ⚠️ 不要直接跑 `pyinstaller MyNotepad.spec`：它会清空整个 `dist/MyNotepad`，
> 而你的笔记库、附件、背景图就在 `dist/MyNotepad/data/` 里。手工执行前务必先备份 `data/`。

## 数据库体积

程序启动时（后台线程，备份之后）会检查数据库的**空闲页占比**，超过 30% 就自动 `VACUUM` 回收。
SQLite 删除或改写大字段后**不会**把空间还给文件系统——图片外置迁移与历史版本快照的删除都会
持续堆积空闲页。实测某库：12.02 MB 的文件里有效数据只有 0.12 MB（空闲页占 99%），
启动一次后即回收为 0.12 MB，数据完整性校验通过。

## 提醒与「关掉窗口还响不响」

提醒原先只由前端的 30 秒轮询触发，**窗口一关就彻底不提醒**。现在关闭窗口默认是**隐藏到托盘**
（进程与提醒线程继续跑），所以：

- 点右上角 ×：窗口隐藏，提醒继续生效（第一次会弹气泡说明「已最小化到托盘」）；
  右键托盘图标可以「打开我的记事本」或「退出」。
- 窗口隐藏或最小化时，到期提醒由**后端**线程补一条托盘气泡（窗口可见时仍走应用内 Toast，
  避免同一条提醒弹两次）。
- **四个开关**都在**提醒列表面板**底部：「关闭窗口后驻留托盘」「开机自动启动」
  「全局快速记录热键」（任意界面按 `Ctrl+Alt+N` 叫出窗口并新建笔记，默认关，被占用会提示）、
  「快速记录窗热键」（`Ctrl+Alt+S` 弹出迷你输入框，Enter 收进「收件箱」，同样默认关），
  改完立即生效（开机自启仅打包版可用）。关掉「驻留托盘」后，点关闭就真的退出，提醒也不再触发。

## Markdown 笔记与格式互转

**新建的笔记默认是 Markdown**（`.md` 文本），历史笔记仍然是富文本（Quill Delta），两者可以互转。

- **编辑**：左边写源码、右边实时预览（滚动同步）；窄窗口自动只留源码一栏
- **工具栏**：H1-H3 / 加粗 / 斜体 / 删除线 / 行内代码 / 列表 / 待办 / 引用 / 代码块 / 表格 / 分割线 /
  链接 / 图片 / 附件 / 公式（快捷键 Ctrl+B / Ctrl+I / Ctrl+K / Ctrl+`）
- **格式徽标**（标题栏右侧）：显示当前是 `MD` 还是 `富文本`，点一下就能互转
  - 富文本 → Markdown：颜色/字号/字体/下划线写成**内嵌 HTML**（我们和 Obsidian 都能显示），
    分割线变 `<hr class="divider-N">`，贴纸变 emoji；**转换前自动留历史版本 + 原始富文本备份**
  - 有备份时点徽标 = **无损还原**（直接用当初那份原始富文本）
  - 没有备份的 Markdown → 富文本 = 有损转换（会先说明，再留历史版本）
  - 两个方向都有**内容守恒校验**：发现会丢字就拒绝转换，笔记原样不动
- **导入 `.md` 文件**：原样保存（不做转换，一个字符都不改）
- **导出**：当前笔记可导出 Markdown（图片复制到同级 `.assets/`）

> 为什么不做"纯 Markdown 存储"：字体/字号/颜色/贴纸/装饰分割线在 Markdown 里没有对应写法，
> 全库改 Markdown 等于删掉这批能力。现在这样——新笔记 Markdown、老笔记按需转换、随时可回退——
> 既拿到纯文本的可迁移性，又不丢已有内容。

## 编辑器手感（状态栏 / 大纲 / 查找替换 / 代码高亮）

- **底部状态栏**：`字数 · 字符 · 段数 · 预计阅读时长`，选中一段时前面多一项「选中 N 字」。
  字数口径与侧栏的派生索引**逐字符一致**（同一套 Markdown 剥离规则：中日韩按字、拉丁按词），
  只是状态栏算的是**未保存**的输入。`tests/test_editor_ux.py` 会拿 `backend.py` 的正则对象
  去比对前端源码，两边改歪一个字符就会失败。
- **大纲抽屉**：状态栏右侧「大纲」按钮打开，列出 H1–H6（代码围栏里的 `#` 会跳过），点击跳转、
  光标移动时自动高亮最近的一条。**刻意不做折叠正文**——折叠可编辑内容会和光标位置、保存链路打架。
- **笔记内查找替换**（`Ctrl+F`，焦点在编辑器里时）：Markdown 笔记有全部匹配高亮、上一个/下一个、
  替换、全部替换（含区分大小写）；**富文本笔记只查找跳转**——在 Delta 里替换要动自定义 blot
  （贴纸/分割线/表格）的序列化，风险远大于收益，界面会直接提示「先转成 Markdown」。
  `Ctrl+F` 焦点不在编辑器里时仍然是聚焦侧栏搜索框（两条规则互不抢）。
- **代码块语法高亮**：Markdown 预览与富文本代码块都用 highlight.js，配色映射到主题变量
  （不 vendor 官方 CSS——它把颜色写死，与 4 套浅色主题 + 深色对不上）。富文本代码块还带一个
  语言下拉（Quill 自带），选完即时着色。

## 知识网络（属性 / 双链 / 表格视图）

### 属性（front-matter）

Markdown 笔记可以在正文最上方写属性：

```markdown
---
状态: 进行中
截止: 2026-10-01
重要: true
标签: [甲, 乙]
---

正文从这里开始……
```

- 标题下方会出现一行属性 chips（`状态 进行中`、`截止 2026-10-01`），点一下展开编辑面板：
  加行 / 改值 / 换类型（文本・日期・复选・列表）/ 删行；**改的是正文那一段**，其余字符一个都不动
- **正文是唯一真相**：面板不是第二个数据源。所以改正文属性，面板跟着变；改面板，正文跟着变，
  不会出现"两处不一致该信谁"的问题
- 属性**不算正文**：字数统计、列表摘要、全文索引都不带上它（它有自己的查询语法）
- 搜索：`prop:状态`（有这个键）/ `prop:状态=进行中` / `prop:截止>2026-10-01` / `prop:标签~甲` /
  `has:prop`，可以 `-prop:…` 取反
- 富文本（Delta）笔记没有 front-matter 这个概念；属性行会直接给一个「转成 Markdown」的按钮

### `[[双链]]`

- 写法：`[[标题]]`、`[[标题|别名]]`、`[[标题#小节]]`、`[[#本笔记的小节]]`
- 预览里渲染成可点的链接；**指向不存在的笔记会标红**，点一下就新建这篇笔记（先生成、回头再写）
- 状态栏右侧「链接」抽屉分三组：
  - **指向**：这篇笔记提到的（显示你当初写的别名）
  - **反向链接**：谁提到了这篇（显示**对方笔记的标题** + 命中处的上下文片段）
  - **尚未创建**：指向还不存在的笔记，点一下即可创建
- 链接按**标题解析**（大小写与首尾空格不敏感；同名多篇时打开最近更新的那篇并提示）；
  解析发生在**查询时**，所以给目标笔记改标题后，所有反向链接会自动跟着修正，没有需要重建的索引
- 目标在回收站里视为"尚未创建"（不会链到一篇看不见的笔记）

### 表格视图

- 侧栏底部「表格」打开，覆盖编辑区；列：标题 / 笔记本 / 标签 / 更新时间 / 字数 / 待办 / 最近到期 +
  每个用到的属性各一列
- **列表看到的 = 表格看到的**：表格显示的永远是当前筛选后的那批笔记，搜索语法
  （`tag:` `todo:open` `prop:状态=进行中` …）与保存的视图直接复用，没有第二套筛选
- 点列头排序（中文按拼音、数字按数值），点一行打开那篇笔记，「导出 CSV」导出**当前筛选**的结果
  （带 BOM，Excel 双击打开不乱码）；加密笔记只显示标题与「已加密」，派生数据一律留空

## 待办、视图与命令面板

**待办**写在笔记正文里就是普通 Markdown 文本（因此别的软件也认）：

```markdown

```

- 侧边栏底部的「待办」打开**跨笔记待办清单**：全部 / 今天 / 逾期 / 本周 / 无日期 / 已完成
- 面板里勾选会**直接写回原文**（Markdown 改 `- [ ]`→`- [x]`；富文本笔记翻行属性）；
  写回前会核对文本，正文被改过就拒绝并让你刷新——不会翻错一条
- 勾待办**不创建历史版本**（否则 50 条历史会被待办刷满）
- 日期语法是 Obsidian Tasks 的 `📅 YYYY-MM-DD`；不带日期的待办落在「无日期」里
- **加密笔记不参与待办与统计**（与“搜索不索引密文正文”同一条隐私约定）

**保存的搜索**：把 `tag:数学 todo:open` 这类查询存成侧栏「视图」里的一个条目，点一下套用。
它只是查询的快捷方式，**不改变任何笔记的归属**，删掉也不影响数据。

**命令面板**：`Ctrl+P` 打开后直接输入是跳笔记，输入 `>` 变成命令面板
（新建/转换格式/导出/待办/版本/回收站/主题/保存当前搜索为视图…）。

**标签层级**：标签名里写 `/` 就是层级（`项目/子项目`），搜 `tag:项目` 会**自动包含**所有子标签；
标签管理面板支持重命名（改名即改层级）与合并到另一个标签。

## 备份与恢复

程序启动时会自动备份（>24h 触发，`data/backups/` 滚动保留 7 份），但**"有备份"和"能恢复"是两件事**，
所以仓库里带了一个不依赖界面的恢复工具（界面起不来时正好用得上）：

```bash
python restore.py --list              # 列出可用备份（时间/大小/篇数，区分自动备份与恢复前快照）
python restore.py --from latest       # 用最新一份恢复
python restore.py --from notes-20260920-235857.db
```

它会：核对备份完整性 → 拒绝在应用运行时执行 → 覆盖前把**当前库**另存为 `pre-restore-<时间>.db`
→ 才覆盖并核对恢复后的篇数。任何一步失败都不会改动当前库。

> 本项目有两处数据目录：源码运行用仓库 `data/`，打包版用 `dist/MyNotepad/data/`。
> `restore.py` 会挑 `notes.db` 最近修改的那份并**打印挑选理由**；也可以 `--data-dir` 显式指定。

## 自定义背景图与界面可读性

用自定义图片当背景（尤其是色彩丰富的壁纸）时，工具栏、标题、标签行、状态栏这些"功能键"
容易被图吃掉。现在按三层机制处理：

1. **按区域自动换色**：把背景图按「cover + 缩放 + 位置」画到一张小画布，分成
   **标题 / 上半 / 正文 / 状态栏**四条带各自算亮度，然后让每一行界面**按它自己那块图**切换
   深字或亮字（并配对应的文字阴影）。为什么不整图算一次：一张图常常上半亮下半暗，
   整图一个判断必然有一半界面读不清。
2. **背景模糊**（0–20px）：给花哨的图降噪，文字和图表都更容易分辨。
3. **界面不透明度**（0–100%）：给界面层盖一层主题色**磨砂薄纱**（一整片，不是逐行），
   **正文区始终保持全透明**（"沉浸式"的前提），薄纱颜色跟随主题、不跟随图片。
   薄纱用遮罩让"色调 + 模糊"一起淡出 —— 界面层到正文区是**渐变过渡**，不是一条硬边；
   高度按内容区顶边实时算，工具栏换行或 Markdown↔富文本切换都会自动跟上。

- 两个滑杆在「背景设置」面板里，全局背景与当前笔记各一套；笔记自带背景图时以笔记设置为准
- 清掉背景图后，界面会自动回到主题常规配色（不会留下上一次图片的明暗判断）

## 已知限制

1. 前端为**原生 ES 模块**（无打包器/构建工具）：跨文件依赖显式写在 `import` 里，加载顺序由模块图
   决定；新增模块只需被 `js/app/00-main.js`（或其依赖）import 到即会加载
2. 编辑器内**复制**图片走 Quill 剪贴板，粘贴出的副本仍以 data URI 内嵌，下次启动迁移外置
   （用按钮插入/拖拽的图片本身已外置到 `attachments/`）
3. 任务栏图标需重启应用后更新（pywebview 框架限制）
4. **提醒依赖进程存活**：默认关窗驻留托盘；若关掉「驻留托盘」或从托盘选了「退出」，
   提醒就不再触发（没有用系统计划任务，这是刻意的取舍：不往系统里塞计划任务）
5. 「纸张样式」（白色/米黄/牛皮/羊皮纸）是显式选择的纸张颜色，**不随深色主题反转**——
   它是「纸」的隐喻，深色主题下就是深色桌面上铺一张浅色纸
6. **Markdown 里的富文本靠内嵌 HTML**：颜色/字号/字体/下划线写成 `<span style>` / `<u>` 等，
   本应用与 Obsidian/Typora 能正常显示，**Joplin 等不渲染 HTML 的软件会丢**；贴纸只能存成 emoji
   （浮动位置丢失）；表格是 GFM 表格（没有合并单元格）
7. **全局热键固定 `Ctrl+Alt+N`**（不可自定义）：被其他程序占用时注册失败，开关会自动弹回关闭
8. **属性只支持 Markdown 笔记**：front-matter 是 Markdown 的概念，富文本笔记请先转成 Markdown
   （属性行里有转换入口；转换本身有备份与内容守恒校验）
9. **双链暂不做输入自动补全**：`[[` 不会弹出候选列表（要点在于先有可跳转、有反向链接，
   补全属于手感优化）；双链匹配的是**标题**，不是文件名或 UUID

## 窗口尺寸与位置

窗口初始尺寸/位置不写死，启动时读取**可用工作区**（已排除任务栏，并按 DPI 换算成逻辑像素）
后居中放置，因此：

- 高 DPI 缩放屏（如 200%）下不会再出现下沿被任务栏压住、底部按钮（日历/回收站）看不见的情况
- 工作区较小（笔记本、缩放后逻辑分辨率低）时自动收缩，最小不小于 900×600；
  工作区本身就小于 900×600 时优先保住可用尺寸（允许略微溢出，但左上角一定可见）
- **记住上次的大小与位置**：关窗时把几何写入设置，下次启动恢复；只有保存的位置能让窗口
  **完整**落在工作区内时才采用，否则退回居中（显示器被拔掉/分辨率变小后旧坐标常常整个在屏外）
- 调整默认尺寸改 `app.pyw` 的 `DEFAULT_WIN_W` / `DEFAULT_WIN_H`（仍会被工作区钳制）
- 该逻辑是纯函数（`clamp_window_geometry`），由 `tests/test_window_geometry.py`（10 种工作区配置）
  与 `tests/test_window_persistence.py`（偏好位置越界/负坐标/坏数据/往返读写）覆盖，防止回归

> ⚠️ 窄窗口曾有一个真实缺陷：编辑器所在网格的列被工具栏 826px 固有宽度撑住，窗口窄于此时
> 右侧被 `overflow:hidden` 裁掉（实测 900px 宽时编辑器少 209px、**4 个工具栏按钮点不到**，
> 而 1024×768 屏与高 DPI 缩放机器**一启动**就会触发）。已用
> `grid-template-columns: minmax(0, 1fr)` + 工具栏格式组换行修复，
> 并由 `tests/test_ui_layout.py` 在 1200/1000/900 三档宽度下测量断言。

## 自定义图标与重新打包

「更换图标」写入的是 `dist/MyNotepad/resources/icon.{png,ico}`，而重新打包会清空 `dist/MyNotepad`
并把它还原成仓库默认图标。为此程序每次启动会把自定义图标备份到 `data/custom_icon/`，
检测到被还原成默认图标时自动恢复（删除 `data/custom_icon/` 即放弃该备份）。

桌面快捷方式的图标则**指向 exe 内嵌资源**（`MyNotepad.exe,0`），由 `build.py` 自动维护——
不再依赖 `resources/icon.ico` 是否存在，因此重新打包不会让快捷方式变成白图标。

> ⚠️ 用 `python build.py` 打包即可（它会自动备份并还原 `data/`）。
> 若坚持手工 `pyinstaller`，务必先备份整个 `dist/MyNotepad/data/`。

## 前端脚本加载

前端分两部分：

- **第三方 UMD 库**（`quill.js`、`katex`、`vendor/` 下的 markdown-it / DOMPurify / CodeMirror）：
  由 `index.html` 末尾的加载器按顺序注入，
  单个文件失败自动重试（最多 4 次，重试带 `?retry=N` 绕开缓存）。WebView2 偶发会拉取失败个别脚本
  （实测约 1/20），不重试就会静默缺功能。
- **应用自身**（`renderer/js/` 下 19 个模块）：是一个 **ES 模块图**，唯一入口 `js/app/00-main.js`。
  每个文件显式 `import` 自己用到的东西，加载顺序由模块图决定。

改成模块是为了消除一个结构性隐患：改造前这些文件是经典脚本，靠「全局作用域 + 加载顺序」互相依赖，
`utils.js` 一挂就会让依赖它的 6 个模块在顶层抛错而整段不执行，表现为「新建笔记点了没反应」＋
「工具栏按钮图标消失」。模块化后依赖关系是显式的，缺文件不再可能造成「界面半死」——要么整图
成功，要么整体失败并在窗口顶部明确报错（并写 `error.log`）。

模块图失败时用**整页 reload**重试（上限 4 次，计数存 sessionStorage）：浏览器会把「取不到的模块」
记进本次文档的模块表，同一文档内再试也不会重新请求，reload 才能拿到全新的模块表。

回归测试见 `tests/test_frontend_modules.py`（静态检查：孤儿模块 / import 了不存在的导出 /
忘了 import；无需浏览器，属默认单测）与 `tests/test_boot_loader.py`（无头 E2E：干净启动、
经典脚本失败重试、模块图失败明确报错、失败后整页重试到上限）。
